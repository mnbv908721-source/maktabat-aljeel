مكتبة الجيل — الهيكل الأساسي

تشغيل محلي: افتح PowerShell داخل هذا المجلد، وشغّل:
node serve.cjs
ثم افتح http://127.0.0.1:43170

التقنيات: HTML + CSS + JavaScript، مع jsPDF 4.2.1 وخط Amiri محليين، بدون قاعدة بيانات أو طلبات لخدمات خارجية.
التنقل: الرئيسية، المفضلة، السلة، الطلبات، الملفات، الحساب.
المفضلة والسلة تُحفظان في localStorage على الجهاز فقط.
الكتب والمؤلفون والأسعار بيانات تجريبية. لا يوجد شراء أو تسجيل دخول حقيقي.

PWA: يتضمن manifest وأيقونات PNG قياسية وmaskable وService Worker.
العمل دون اتصال متاح بعد زيارة ناجحة وتحميل الملفات أول مرة.
لتثبيته على هاتف، استضف الملفات عبر HTTPS. عنوان localhost هنا مخصص للجهاز الحالي.
أندرويد: من قائمة المتصفح، تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
آيفون: Safari > مشاركة > إضافة إلى الشاشة الرئيسية.
عند تحديث الملفات، غيّر إصدار CACHE في sw.js حتى تُحدّث الملفات المخزنة.

لا تنشر serve.cjs على خادم إنتاج؛ ارفع ملفات الواجهة والأيقونات فقط إلى استضافة ثابتة.

تحديث الرئيسية: بوستر العروض، تبويبا المنتجات والخدمات، ٤ منتجات و٣ خدمات تجريبية، فلترة حسب التصنيف وترتيب حسب السعر أو الاسم. الصور SVG محلية ومتاحة دون اتصال بعد الزيارة الأولى.

السلة: مثال من ٣ منتجات عند أول تشغيل للتحديث. يُحفظ تعديل الكميات والحذف محلياً، وتبقى السلة فارغة بعد إفراغها. زر إتمام الطلب يولّد PDF A4 عربياً محلياً مع التاريخ بتوقيت بغداد والمجموع الفعلي؛ لا يرسل طلباً ولا يحصّل مبلغاً. بعد التنزيل اضغط فتح الفاتورة للطباعة، ثم اطبع من قارئ PDF. يعمل التوليد دون إنترنت بعد تحميل ملفات التطبيق أول مرة.
المكتبات: vendor/jspdf.umd.min.js (MIT)، fonts/Amiri-Regular.ttf (OFL)، ملفات التراخيص مضمّنة.


تحديث الملفات والطلبات: مكتبة رقمية تجريبية تضم ٣ مقاطع WebM قصيرة أصلية بدون صوت، وحفظ تقدّم المشاهدة محلياً عند انتهاء الدرس. كتاب PDF عربي من ٣ صفحات مع قارئ صفحات داخل التطبيق ورابط فتح/تحميل الملف الأصلي. سجل من ٣ طلبات وهمية مع حالات ملوّنة وتفاصيل الأصناف. التنقل بالأقسام الستة عبر hash دون إعادة تحميل المستند. الملفات المضمّنة تعمل دون إنترنت بعد تحميلها الأول. يلزم متصفح يدعم WebM لتشغيل المقاطع.


اكتمال الهيكل الأمامي: المفضلة تستخدم نفس بطاقات الرئيسية مع قلوب حمراء، ومثال أولي من ٣ عناصر يُضاف مرة واحدة فقط، وحالة فارغة ثابتة بعد الإزالة. الحساب يعرض صورة رمزية وبيانات وهمية وخيارات تعديل البيانات وتغيير كلمة المرور والدعم والخروج. تعديل الاسم والبريد محلي فقط. نموذج كلمة المرور لا يخزن أو يرسل قيماً ولا يغيّر أي حساب حقيقي. الخروج والاستعادة محاكاة محلية، مع الحفاظ على السلة والمفضلة. تم فحص التنقل بالأقسام الستة دون إعادة تحميل، وواجهات الموبايل والعمل دون اتصال.
