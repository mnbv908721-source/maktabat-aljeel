# مكتبة الجيل — واجهة الزبون

واجهة عربية متجاوبة لتطبيق PWA، تعمل بملفات HTML وCSS وJavaScript دون قاعدة بيانات.

## التشغيل المحلي

يتطلب Node.js. شغّل من مجلد المشروع:

```sh
node serve.cjs
```

ثم افتح `http://127.0.0.1:43170/`.

## الأقسام

- الرئيسية: منتجات وخدمات، بحث وتصنيف وفرز.
- المفضلة: حفظ محلي وحالة فارغة.
- السلة: كميات وحذف وإجمالي وفاتورة PDF عربية.
- الطلبات: سجل وهمي بحالات وتفاصيل.
- الملفات: دروس فيديو وكتاب PDF تجريبي.
- الحساب: ملف شخصي وإجراءات محلية تجريبية.

التنقل SPA دون إعادة تحميل المستند. تثبيت التطبيق على الهاتف يتطلب استضافة HTTPS، والعمل دون اتصال متاح بعد تحميل الملفات أول مرة.

## حدود النسخة

المنتجات والأسعار والطلبات والحساب بيانات وهمية. لا توجد مصادقة أو خدمة دفع أو إرسال طلبات. المفضلة والسلة والملف الشخصي والتقدم محفوظة في المتصفح فقط. لا تُدخل كلمات مرور حقيقية في النموذج التجريبي.

واجهة الإدارة ستكون مشروعاً مستقلاً؛ هذا المستودع خاص بواجهة الزبون.

## الأصول والتراخيص

jsPDF 4.2.1 بترخيص MIT في `vendor/`، وخط Amiri بترخيص OFL في `fonts/`. ملفات التراخيص مضمّنة. أغلفة SVG ومقاطع الدروس والكتاب أمثلة توضيحية أصلية للمشروع.

ملف `serve.cjs` للمعاينة المحلية فقط. للاستضافة الثابتة ارفع ملفات الواجهة والمجلدات التابعة لها. حدّث إصدار `CACHE` في `sw.js` عند تغيير ملفات التطبيق.
